O JavaScript está desligado neste navegador

O sistema precisa do JavaScript para funcionar. Abra este arquivo no Microsoft Edge ou no Google Chrome. Se já está num deles, o JavaScript foi desligado nas configurações (ou por regra da empresa): peça ao suporte para liberar o JavaScript para arquivos locais.

Enquanto isso, a planilha .xlsx pode ser aberta normalmente no Excel.
